# Sauti Yako Logo Package

## Brand direction

**Sauti Yako** means “your voice.” The identity is designed for a university-affiliated organization focused on gender-based violence prevention, survivor support, awareness, and safe reporting. The microphone represents voice and listening; the protective shield represents safety and institutional care; the interlocking human forms represent equality, solidarity, and inclusion. Palm, sun, and ocean-wave gestures provide a restrained Zanzibar and SUZA-inspired context without reproducing the official SUZA crest.

> This package is a coordinated concept system. Before official adoption, the logo should be redrawn as editable vector artwork and approved by the relevant SUZA authority.

## Usage rules

Use the horizontal lockup whenever there is enough width. Use the vertical lockup when the available space is taller than it is wide. Use the app icon or minimal mark when the logo must remain recognizable at a small size. Use one-color versions for stamps, photocopies, embossing, embroidery, and low-ink production.

Keep generous clear space around the logo, approximately the height of the microphone head on all sides. Do not stretch, rotate, outline, add shadows, apply gradients, change the palette arbitrarily, place the light version on a dark background, or place the dark version on a busy image. Do not combine the mark with the official SUZA crest unless that placement has been approved by SUZA.

## Suggested typography

For final vector production, pair the mark with a bold geometric sans-serif wordmark for **SAUTI YAKO** and a smaller neutral sans-serif line for **SUZA • ZANZIBAR**. The generated images show the intended hierarchy; a designer should set the final text using licensed vector type so spacing and spelling remain exact across print and digital applications.
